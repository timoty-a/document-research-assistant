## Retrieval and citation contract

- Select one to five documents. Validate all IDs against the authenticated owner in SQL; reject the entire selection with the same `404` for unknown, ownerless and other-user IDs. No partial success that leaks source existence.
- Use existing immutable TXT content/PDF page text. No new migration or retroactive ownership operation is required. PDF chunks never cross physical pages; TXT citations have offsets without invented page numbers.
- Chunk into bounded, overlapping windows of the **original** text; rank using deterministic lexical term coverage/frequency. Normalization is a search-only copy. This baseline misses synonyms and some languages; do not claim semantic search or comprehensive evidence discovery. Bound selected source bytes/chunk count, return at most six nonredundant passages, and report no match without invoking AI.
- Citation provenance: document UUID, extraction version (`txt:utf8-v1` for TXT), physical PDF page or null, original Unicode-code-point start/end offsets, exact quote, and filename supplied by our database. Model output cannot choose filenames, locations or arbitrary URLs.
- Each model claim must cite request-local evidence IDs from the retrieved set. Reject unknown IDs, missing references, malformed/incomplete/refused output, excessive text and fabricated quote fields. Resolve references on the server. These checks prove reference integrity, **not** semantic entailment; the UI explicitly asks the user to verify each claim against the quote/context. No unsupported uncited prose presented as a verified answer.
- An owned passage endpoint returns a bounded surrounding-text window and the exact cited slice. Recheck authentication/ownership/version/ranges on every read. Render all user/model/document strings as text; no raw HTML/Markdown links. Unicode offsets are code points; JavaScript must not use UTF-16 offsets directly for slicing.

## Boundaries and request flow

Header/session/Origin/CSRF checks precede question JSON parsing. Bound JSON to 8 KiB; question 1–1,000 characters, no NUL, up to 20 search terms, and five unique UUIDs. New routes share no-store/session-context response headers. Blocking SQL/retrieval/provider calls run in workers, not async handlers.

Authenticate and load selected content inside a short transaction. Never hold a session lock/database transaction during network generation. Revalidate the original session/CSRF and ownership immediately before sending, and again before returning the result. Logout after disclosure cannot recall a provider request, but prevents its delayed answer from reaching the new session. The pre-send check cannot be atomic with the remote network request: logout may race with an already-authorized disclosure. Do not promise to recall it. Abort/stale-generation guards clear sources/questions/answers/passage context on logout, account change and source-selection change; stale `401` responses cannot invalidate a newer session. No automatic replay of any question or upload.

Use per-process concurrency control and persisted per-account/project request budgets before a provider call. A lost provider response may incur cost; do not automatically retry or claim it was free. No question/answer persistence in this prototype; saved conversations remain a later milestone.

## Implemented API and verification record — 18 October 2026

- `GET /research/status`: authenticated configuration status (`enabled`, `provider`, `model`), not provider connectivity.
- `POST /research/search` and `POST /research/questions`: JSON `{question, document_ids}`. Search never calls a provider; questions synthesize only when enabled and evidence exists. Return question, status (`evidence_only`, `no_evidence`, `answered`, `insufficient_evidence`), claims with citation IDs, server-derived citations and warnings. Selection validation is all-or-nothing.
- `GET /documents/{id}/passage?start=…&end=…&version=…&page=…`: owned exact quote and at most 200 surrounding code points on each side. Page zero denotes TXT in the request, null in responses. Reject stale extraction version (`409`), invalid ranges (`400`/`422`) and unavailable ownership/page (`404`). No full document download.
